# My Portfolio

A personal portfolio website built with HTML and CSS, with a denim-inspired design.

**Live site:** https://antonatte1.github.io/Portfolio/

## What's inside
- An About section, a Projects section, a Skills section, and contact details
- A responsive layout that works on phones and desktops

## Built with
- HTML5
- CSS3 (variables, flexbox, grid, media queries)
- Hosted on GitHub Pages
